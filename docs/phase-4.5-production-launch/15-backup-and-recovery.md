# Backup and recovery

`scripts/production-backup.sh` streams a custom-format `pg_dump` directly into GPG encryption and verifies it with `pg_restore --list` inside the PostgreSQL container. It also creates an encrypted archive of regular files under `MEDIA_ROOT` (default `/home/rakmyat/data/uploads`) with a SHA-256 file manifest and file/byte counts. Empty media directories are valid and produce a manifest with zero entries. Verified artifacts are published without replacing existing names; failed temporary artifacts are marked `.FAILED`.

The script requires the matching GPG private key to be available in the operator's GPG keyring because it decrypts both archives for verification. The VPS previously showed no root-owned secret key, so this prerequisite must be resolved before running it. Select an approved key custody policy and protected off-host `BACKUP_DESTINATION`; restrict permissions and configure retention/immutability with the selected provider. The encrypted database and media archives contain no plaintext copies on disk; only the small generated media manifest and metadata use a protected temporary directory during backup.

`scripts/production-restore-drill.sh` requires a pre-created disposable target and refuses the production/default database names. It will not drop or create a database. `scripts/production-media-restore-drill.sh` requires a pre-created empty disposable directory and verifies the manifest, file count, total bytes, and SHA-256 checksums after extraction. Review and rehearse both scripts against disposable resources before relying on production backups.

These scripts must never be run against production as a restore drill. No off-host key, destination, retention policy, or schedule is established by this repository. A local Phase 4.3 synthetic restore is documented in that phase's evidence. Provisional targets for owner discussion: RPO 24 hours and RTO 4 hours; select stricter values if inquiry volume or business needs require them. Keep encryption private-key recovery separate and tested.
