# Accessibility

Phase 4.1 documents safe fixes to accessible names, heading semantics, contrast for named elements, and a 44px minimum mobile menu target. Automated Lighthouse reached 100 on four sampled EN/AR Home/Services routes; this is not WCAG 2.2 AA certification. Current broad route matrix checks one H1 count but does not evaluate accessible names, contrast, keyboard order, or semantics.

**Status: IMPROVED / NEEDS MANUAL REVIEW.** Keyboard-only navigation, focus visibility across states, skip link, screen reader announcements, 200-400% zoom, 320px reflow with text enlargement, touch-target inventory, modal focus trap/return, reduced-motion behavior, and assistive technology/browser combinations remain unverified sitewide.
