# Owner decisions required before release

The audit identified decisions that code changes cannot safely infer:

1. Approve the production domain, HTTPS host, canonical origin, DNS ownership, and whether indexing should be enabled.
2. Provide rights evidence for theme/fonts and permission to publish each project name, mark, and screenshot.
3. Approve English copy, Arabic proofreading, service claims, and the How We Work process wording.
4. Approve privacy notice, lawful basis, retention period, deletion/export workflow, and public contact expectations.
5. Select production hosting/database/email providers and name the operator responsible for secrets, migrations, backups, restore, monitoring, incident response, and rollback.
6. Approve the accessibility release bar and complete manual WCAG 2.2 AA review.
7. Approve admin exposure, account lifecycle, and operational ownership.

Until domain, contact delivery, privacy, and licensing decisions are completed, the website should remain a local review build and indexing disabled.
