# Schooly before and after

Schooly was used as the first implementation and reference case. Source contact sheets confirmed that `schools-desktop.webp` (1425x5727) and `school-detail-desktop.webp` (1425x4182) are complete desktop pages, while `compare-desktop.webp` (1425x1195) is a useful, denser comparison screen. The former contain readable product UI at the top and become tiny when the entire page is fit inside a landscape card.

The hero remains the approved 1440x900 English Schooly homepage capture. Gallery images now use explicit native dimensions and a presentation mode. The two full-page sources show a top-focused landscape preview at page scale; landscape screens retain their own ratio; the actual mobile profile stays in a phone frame. Each click opens its untouched original. The grid uses top alignment and no forced mobile row span.
